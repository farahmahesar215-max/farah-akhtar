# Farah Akhtar — Portfolio

Academic portfolio and CV site for Dr. Farah Akhtar, PhD in Economics, Universiti Tunku Abdul Rahman (UTAR), completed June 2026.

Live site: https://farahmahesar215-max.github.io/farah-akhtar/

## Contents

- `index.html` — page markup and content
- `teaching.html` — teaching portfolio (philosophy, record, evaluations, courses)
- `style.css` — styling

## Local preview

Serve the folder with any static file server, e.g.:

```
python -m http.server 5500
```

Then open `http://localhost:5500`.
